# Dimensy patches for Frappe Helpdesk

Base: Helpdesk v1.30.1 (branch `release/1.30`). One commit per patch, written as [Conventional Commits](https://www.conventionalcommits.org/) with a `Dimensy-Patch: Pn` trailer (find them with `git log --grep "Dimensy-Patch"`). Plan: `docs/patch-plan.md` in the Dimensy project repository.

| # | Commit | Files | Purpose |
|---|---|---|---|
| P1 | `fix(api): hide internal ticket data from non-agents` | `helpdesk/utils.py`, `helpdesk/helpdesk/doctype/hd_ticket/api.py`, `test_hd_ticket.py` | `get_one` drops `INTERNAL_TICKET_FIELDS` (priority, team, SLA fields, `_assign`, `_comments`, ...) for non-agents. `get_communications` replaces the sender of agent replies with a team name (site config `helpdesk_customer_agent_name`, default "Support Team") and drops `bcc`. Decided on the server from the user's role, not from a client parameter. Agent behavior is unchanged. Test: `test_get_one_hides_internal_data_from_non_agents`. |
| P2 | `fix(api): strip internal columns from the customer ticket list` | `helpdesk/api/doc.py`, `test_hd_ticket.py` | `get_list_data`, `sort_options` and `get_quick_filters` force portal mode for non-agents. Columns, rows and data requested by the client are filtered with `INTERNAL_TICKET_FIELDS`. Portal field lists no longer include `priority`, `response_by` or `resolution_by`. Test: `test_get_list_data_hides_internal_columns_from_non_agents`. |
| P3 | `fix(portal): remove Team, Priority and SLA from the customer ticket sidebar` | `desk/src/components/ticket/TicketCustomerSidebar.vue` | Removes the Team and Priority rows and the SLA block (First Response, Resolution) from the portal customer sidebar, together with the now-unused SLA imports and computations. Test: Playwright (customer, desktop and mobile). |
| P4 | `chore(ui): rebrand the help panel to Dimensy Helpdesk` | `desk/src/components/layouts/Sidebar.vue` | Help/onboarding panel title "Frappe Helpdesk" becomes "Dimensy Helpdesk". |
| P5 | `fix(ui): show the full user name from the server` | `desk/src/stores/user.ts` | `full_name` from `get_users` is no longer overwritten by the email prefix ("Cs1"); assignee names in the chip and dropdown follow the User data. |
| P6 | `fix(ui): do not load HD Agent Status for customers` | `desk/src/stores/agentStatus.ts` | The agent status list is only fetched for sessions that have an HD Agent record, which removes the "Insufficient Permission for HD Agent Status" toast on the customer mobile view. Side effect: accounts without an HD Agent record (e.g. admin) do not see agent presence dots. |
| P7 | `feat(portal): link to the source code in the customer sidebar` | `helpdesk/www/helpdesk/index.py`, `desk/src/types.ts`, `desk/src/components/layouts/Sidebar.vue` | AGPL section 13: customers of the modified portal get a visible "Source code" link. The URL comes from the site config `helpdesk_source_code_url` through the boot context; the link is hidden when it is empty and for agents. |
